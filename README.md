# GitShow

精简的 Git 图形客户端，用来查看改动、暂存、提交、看历史，以及切换分支、拉取和推送。

需要本机已安装 [Git](https://git-scm.com/)，程序通过系统里的 `git` 命令工作。

## 直接运行

双击：

```text
dist\GitShow.exe
```

最近打开过的仓库会记在 `%APPDATA%\GitShow\state.json`，下次启动会自动打开最后一个。程序异常退出时，详情写在同目录的 `panic.log`。

## 从源码构建

需要 Rust 1.85 或更新版本（`edition = 2024`）。Windows 上使用 GNU 工具链时，还要能在 `PATH` 里找到 `gcc`。

```text
cargo build --release
```

生成的程序在 `target\release\GitShow.exe`。开发时也可以：

```text
cargo run
```

## 使用

- **打开仓库**：点「打开仓库」，或把文件夹拖进窗口。拖进去的如果是文件，会改用它所在的目录。
- **更改**：未暂存、已暂存和冲突分开列出。可以暂存、取消暂存、放弃更改。放弃更改和删除未跟踪文件都会先确认。
- **提交**：只提交已暂存的文件。写好说明后点「提交」，或按 `Ctrl+Enter`。成功后会打开这次提交，并列出其中的文件。
- **历史**：窗口下方始终显示最近的提交。点一条记录可查看其中的文件和差异。
- **分支**：左侧列出本地分支，点击即可切换。在输入框里填写名字后点「创建」，会建好并切过去。
- **拉取 / 推送**：用工具栏上的按钮。当前分支还没有上游时，推送会执行 `git push -u origin HEAD`。

工具栏会显示当前分支，以及相对上游领先、落后，或上游已删除。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `F5` | 刷新状态和历史 |
| `Ctrl+Enter` | 提交已暂存的文件 |
